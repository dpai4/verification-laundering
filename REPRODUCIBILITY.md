# Reproducibility Guide

This artifact distinguishes three levels of reproducibility.

## 1. Offline artifact verification

Run from any working directory:

```bash
python scripts/verify_claims.py
```

This standard-library-only check validates required artifacts, published hashes, record counts, H21 provider/model completion totals, the adjudicated H21 BUGGY endpoint, and the H23 paired result. It does not modify frozen data.

## 2. Analysis from frozen outputs

The included analysis programs document how frozen outputs were joined and summarized. `h21_analyze_frozen281.py` represents the pre-adjudication automated analysis; the final adjudicated rows are preserved in `data/h21/h21_joined_adjudicated.jsonl`. `h23_analyze.py` computes the authority-pilot table and exact paired test from frozen labels.

The stronger verification scripts use intermediates in `data/verification/`. `consistency_gate.py` is the earlier draft; `consistency_gate2.py` is the analysis corresponding to the reported simple self-consistency result. `pbt_gate.py` supports Hypothesis and, when installed, its CrossHair backend. The “symbolic analysis” comparison in the paper refers specifically to that backend.

Some analysis scripts write derived files. Work on a copy or confirm the repository is clean before running them; frozen checked artifacts should not be regenerated for routine review.

## 3. Model-generation reruns

Scripts whose names include `h2_`, `h11_`, `h21_cross_vendor`, `h21_grade`, `h23_authority_run`, or `h23_grade` can invoke external model APIs. They are retained for methodological inspection, not offered as a stable one-command reproduction path. Reruns may require provider SDKs and model access, API credentials supplied through environment variables, compatible historical package versions, and model endpoints whose behavior may have changed.

Do not run these scripts merely to verify the artifact. Frozen outputs are the review targets, and no credentials or model responses are regenerated by `verify_claims.py`.

## H22 limitation

H22 is an incomplete external-validity extension. Its protocol, manifests, and partial status file are preserved for provenance, but it does not substantiate a completed or headline empirical claim.
